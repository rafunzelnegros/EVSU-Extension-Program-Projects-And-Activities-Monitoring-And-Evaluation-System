How the forecast works

The system uses a simple least-squares linear trend on each unit's cumulative number of SAVED Projects by Project Start Date and quarter. For the current year, only quarters that have already started are used to fit the trend; future quarters are estimated from that trend. It is an explainable planning estimate—not a guaranteed result, ranking score, or AI judgment.

1. Count project starts per quarter2. Convert to cumulative totals3. Fit a straight-line trend4. Estimate the next quarter and year-end
