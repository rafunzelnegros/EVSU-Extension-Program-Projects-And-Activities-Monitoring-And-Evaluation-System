How the current prediction works

The system uses a simple least-squares linear trend on each unit's cumulative number of SAVED Projects, grouped by the Project's Start Date and quarter. Draft PPAs are excluded. For the current year, the calculation only uses quarters that have already started, so future zeroes do not artificially lower the trend. It then extends that trend to estimate the next quarter and the end of Q4.

1. Count SAVED project starts per quarter2. Convert those counts into cumulative totals3. Fit an explainable linear trend to observed quarters4. Extend the trend for the next quarter and year-end

Important: this is a planning forecast, not a guaranteed result or an AI performance score. With very little history, especially only one observed quarter, the estimate is less stable and should be interpreted cautiously.
